## Architecture at a Glance

```
/gazebo (simulator)
  └─ Physics loop
     └─ Publish /clock

/robot1/robot_state_publisher  (TF broadcaster)
/robot2/robot_state_publisher  (TF broadcaster)

Topics:
  /robot1/odom  [nav_msgs/Odometry]
  /robot2/odom  [nav_msgs/Odometry]
  /tf, /tf_static  [TF transforms]

TF Frames:
  robot1/odom → robot1/base_link → robot1/base_scan
  robot2/odom → robot2/base_link → robot2/base_scan
```

Phase 2 will add:
- `/robot1/scan`, `/robot2/scan` (LiDAR)
- `/robot1/map`, `/robot2/map` (SLAM)
- Nav2 costmaps and planner topics
- `/robot1/navigate_to_pose`, `/robot2/navigate_to_pose` (actions)

See [docs/ros_graph.md](docs/ros_graph.md) for complete topology.

```bash
ros2 topic echo /robot1/odom --once
ros2 topic echo /robot2/odom --once
```

### Inspect Package
```bash
ros2 pkg list | grep sharednav
ros2 pkg prefix sharednav_bringup
```

### Debug Issues

**Gazebo not starting?**
- Ensure WSL2 has --network, --display (if GUI needed)
- Check gzserver is running: `ps aux | grep gzserver`

**Robots not spawning?**
- Check spawn_entity service: `ros2 service list | grep spawn`
- Check GazeboRosFactory plugin loaded: look for "libgazebo_ros_factory.so" in launch

**TF errors?**
- View frames: `ros2 run tf2_tools view_frames`
- Check odom→base_link transforms present
