System Architecture: Perception-to-Action Pipeline with Human-in-Loop Confirmation

Project Overview

This project developed an interactive human-robot system capable of recognizing German Sign Language finger-spelling and physically translating the detected gesture into a written letter using a robotic arm. Conducted at Universität des Saarlandes in Germany, the system combined computer vision, machine learning, embedded control, inverse kinematics, robotic manipulation, custom mechanical design, and a graphical user interface into a single end-to-end perception-decision-action platform. A camera continuously observes the user, a MobileNet CNN recognition model classifies the performed hand gesture, the user confirms the prediction through an additional gesture, and the corresponding character is transmitted to an Arduino-controlled Tinkerkit Braccio robotic arm that writes it on a whiteboard. The resulting prototype achieved an average 80% recognition accuracy across the alphabet and produced recognizable robotic handwriting for 24 of 26 letters, demonstrating a complete perception-decision-action loop for interactive robotics.

Engineering Disciplines & System Architecture

  • Human-Robot Interaction Design: Developed modular perception-to-action architecture separating perception, user interaction, communication, motion generation, and hardware control. Implemented human-in-the-loop confirmation mechanism where left-index-finger raise gesture confirms predictions before robotic execution.
  • Convolutional Neural Network Architecture: Implemented lightweight MobileNet CNN generated through Google Teachable Machine, trained using TensorFlow.js and transfer learning. Focused on 26 principal alphabet characters, replacing dynamic signs for J and Z with representative static poses for image-classification consistency.
  • Dataset Generation & Computer Vision Preprocessing: Generated custom training dataset with different users, backgrounds, and lighting conditions. Integrated Google MediaPipe Hands extracting 21 hand landmarks providing characteristic geometric information about finger and hand configuration. Preprocessed images through cropping to focus on hand regions and reduce background information.
  • Python-Based Interactive User Interface: Developed graphical interface displaying real-time camera stream with current machine-learning predictions. Incorporated deliberate human-in-the-loop confirmation protocol to reduce unintended robot actions from misclassifications. Confirmed letters displayed before robotic execution.
  • Robotic Arm Modification & End-Effector Design: Designed custom writing gripper through iterative mechanical development process using Autodesk Fusion 360 CAD and Ultimaker S5 3D printer additive manufacturing. Prototyped three different concepts before selecting configuration providing highest writing stability. Removed unnecessary servomotors when integrating redesigned tool.
  • Inverse Kinematics & Embedded Motion Control: Implemented inverse kinematics using CGx Inverse Kinematic library, translating desired Cartesian positions on whiteboard into angular values for Braccio servomotor joints. Used trigonometric relationships based on law of cosines and manipulator dimensions. Implemented USB serial communication between computer and Arduino UNO for robotic commands.
  • Robotic Handwriting Algorithm & Software Structure: Developed hierarchical motion-generation algorithm converting alphabet characters into executable robotic trajectories. Each character embedded inside predefined 2D square, decomposed into straight-line segments with individual drawing methods per letter. Implemented explicit drawing and non-drawing states through vertical pen movement.
  • Trajectory Discretization & Motion Accuracy Optimization: Discretized each line into intermediate waypoints at approximately 1 mm intervals to force pen to remain close to desired Cartesian trajectory. Horizontal and vertical strokes generated through one-dimensional interpolation. Diagonal strokes approximated by alternating small horizontal and vertical movements. Experimentally compared multiple trajectory-generation strategies.
  • Experimental Validation & Confusion Matrix Analysis: Evaluated complete system through machine-learning classification tests and physical robotic-writing experiments. Calculated recognition accuracy using 10 test images per character (~80% average). Analyzed confusion matrix to identify systematic errors between visually similar signs. Physical testing identified mechanical backlash, limited robotic reach, joint play, and trajectory-transition errors as primary causes of handwriting inaccuracies.
  • Multidisciplinary Systems Integration: Synthesized computer vision, machine learning, embedded control, robotic kinematics, custom mechanical design, and graphical user interface into unified end-to-end system. Demonstrated hands-on experience in human-robot interaction, Python programming, CNN architectures, transfer learning, Arduino embedded control, CAD/additive manufacturing, and experimental validation methodologies.

Development Process & Engineering Workflow

1

System Architecture & Dataset Generation

Designed modular perception-to-action architecture. Generated custom training dataset with different users, backgrounds, and lighting conditions for 26 German Sign Language alphabet characters. Collected ~100 images per class with visual variability to improve robustness.

2

Computer Vision & Machine Learning Model Development

Implemented Google MediaPipe Hands extracting 21 hand landmarks for geometric feature representation. Developed MobileNet CNN using Google Teachable Machine and TensorFlow.js transfer learning. Preprocessed images through cropping and landmark extraction. Trained model achieving ~80% recognition accuracy through iterative dataset and epoch expansion (40→100 images, 50→100 epochs).

3

Mechanical Design & Robotic Integration

Designed custom writing gripper through iterative mechanical development using Autodesk Fusion 360 CAD. Prototyped three concepts before selecting highest-stability configuration. Manufactured end-effector using Ultimaker S5 3D printer. Integrated with Tinkerkit Braccio arm and Arduino UNO. Implemented inverse kinematics using CGx library and USB serial communication.

4

Software & Motion Algorithm Development

Developed Python graphical user interface displaying real-time camera stream with ML predictions. Implemented human-in-the-loop confirmation protocol using left-index-finger gesture. Created hierarchical robotic handwriting algorithm converting alphabet characters into Cartesian trajectories. Implemented explicit drawing/non-drawing states and 1 mm waypoint discretization for trajectory accuracy optimization.

5

Experimental Validation & System Optimization

Conducted machine-learning classification tests (10 test images per character). Performed physical robotic-writing experiments across all 26 letters. Generated confusion matrix analysis identifying systematic errors between visually similar signs. Identified mechanical backlash, limited robotic reach, and joint play as primary accuracy limitations. Successfully produced recognizable handwriting for 24 of 26 letters (92%). Refined trajectory generation and motion parameters.
